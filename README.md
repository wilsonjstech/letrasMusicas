# Biblioteca de músicas

Backup criado pelo Busca Letras.

- `artistas/`: letras em TXT UTF-8, organizadas por artista.
- `catalogo.json`: letras, metadados e links de origem para recuperação.

As notas internas da aplicação não são enviadas. Os arquivos TXT mantêm o cabeçalho e uma linha vazia entre os blocos. A seleção de quais músicas importar em softwares de projeção é feita pelo usuário.

O catálogo é o formato de recuperação do Busca Letras, não um JSON de importação do Holyrics ou do sPresenter. Use os arquivos TXT nesses programas.
